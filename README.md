# digital-warehouse 🏠

> A project aiming to enable families to manage all the expensive stuff in the household.
>
> 帮助每个家庭管理所有贵重物品的「数字仓库」——记录家里每件值钱东西的名称、购买信息、价格、保修期与存放位置，随时可查、一目了然。

This was generated by Qwen Studio

## ✨ 功能（初版 v0.1）

- 📦 **物品台账**：名称、分类、品牌型号、序列号、价格、数量、购买日期/渠道、存放位置、状态、备注
- 🛡 **保修追踪**：根据购买日期 + 保修月数自动计算，标记「保修中 / 即将过保(90天内) / 已过保」
- 📊 **家庭资产总览**：物品总数、总价值、按分类统计、过保提醒
- 🔍 **搜索与筛选**：关键词全文搜索、按分类过滤、按价值/日期/名称排序
- ⬇ **数据导出**：一键导出全部数据为 JSON（本地文件 `data/items.json` 持久化，无数据库依赖）
- 📱 **响应式界面**：桌面与手机均可使用

## 🚀 快速开始

零依赖，只需 Node.js ≥ 18：

```bash
npm start        # 或 node server.js
# 打开 http://localhost:3000
```

开发模式（文件改动自动重启）：

```bash
npm run dev
```

端口可通过环境变量修改：`PORT=8080 npm start`

首次启动会在 `data/items.json` 生成两条示例数据，可直接删除后录入自己家的物品。

## 🧱 技术选型

| 层 | 方案 | 理由 |
|---|---|---|
| 后端 | 原生 Node.js `http` 模块 | 零依赖、易部署、无需构建 |
| 存储 | JSON 文件（原子写入） | 家庭场景数据量小，备份即复制一个文件 |
| 前端 | 原生 HTML/CSS/JS + `<dialog>` | 免框架、加载快、单页即可完成 CRUD |

## 📡 API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/items?q=&category=&sort=` | 列表（支持搜索/过滤/排序） |
| GET | `/api/items/:id` | 单个物品 |
| POST | `/api/items` | 新增 |
| PUT | `/api/items/:id` | 更新 |
| DELETE | `/api/items/:id` | 删除 |
| GET | `/api/categories` | 分类列表 |
| GET | `/api/stats` | 统计概览 |
| GET | `/api/export` | 导出全量 JSON |
