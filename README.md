# digital-warehouse 🏠

> A project aiming to enable families to manage all the expensive stuff in the household.
>
> 帮助每个家庭管理所有贵重物品的「数字仓库」——**聚焦茶叶、酒品等常见送礼物品**：记录名称、品牌规格、数量单位、购入价与当前估值、生产年份/保质期、存储方法与存放位置，送出/饮用一目了然，临过期自动提醒。

This was generated by Qwen Studio

## ✨ 功能（v0.2 · 茶叶酒品版）

- 🍵 **礼品分类体系**：预置茶叶、白酒、红酒、洋酒、保健品、香烟、礼品、食品等送礼常见分类，支持自定义新分类
- 📦 **库存台账**：名称、品牌、规格型号、数量+单位（瓶/罐/饼/提/箱）、购入价格（整批）、购买日期/渠道、存放位置、备注
- 💰 **价值双轨**：`price` 记购入成本，`valuePerUnit` 记当前单件估值（老酒增值、市价波动时可覆盖），总价值只统计在库部分
- ⏳ **保质期 & 陈化**：绿茶/铁观音/食品填「保质期至」→ 自动标记「保质期内 / 临期(90天内) / 已过期」；白酒、普洱、蜂蜜等可陈化物品留空即显示「宜陈放」不提醒
- 🎁 **送礼流转**：库存状态跟踪——在库 / 部分送出 / 已送出 / 已饮用 / 已食用 / 已闲置 / 已报废，送出即从家庭资产中扣除
- 🧊 **存储方法**：为每类物品记录储存要点（避光、冷藏、恒温横放等），搜索可命中
- 🛡 保修追踪保留（茶具电器等仍可用）
- 🔍 **搜索筛选**：全文关键词、分类过滤、按单价/日期/保质期排序
- ⬇ **数据导出**：一键导出 JSON（本地 `data/items.json` 持久化，无数据库依赖）
- 📱 **响应式界面**：桌面与手机均可使用

## 🚀 快速开始

零依赖，只需 Node.js ≥ 18：

```bash
npm start        # 或 node server.js
# 打开 http://localhost:3000
```

开发模式（文件改动自动重启）：

```bash
npm run dev
```

端口可通过环境变量修改：`PORT=8080 npm start`

首次启动会在 `data/items.json` 生成两条示例数据，可直接删除后录入自己家的物品。

## 🧱 技术选型

| 层 | 方案 | 理由 |
|---|---|---|
| 后端 | 原生 Node.js `http` 模块 | 零依赖、易部署、无需构建 |
| 存储 | JSON 文件（原子写入） | 家庭场景数据量小，备份即复制一个文件 |
| 前端 | 原生 HTML/CSS/JS + `<dialog>` | 免框架、加载快、单页即可完成 CRUD |

## 📡 API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/items?q=&category=&sort=` | 列表（支持搜索/过滤/排序） |
| GET | `/api/items/:id` | 单个物品 |
| POST | `/api/items` | 新增 |
| PUT | `/api/items/:id` | 更新 |
| DELETE | `/api/items/:id` | 删除 |
| GET | `/api/categories` | 分类列表 |
| GET | `/api/stats` | 统计概览 |
| GET | `/api/export` | 导出全量 JSON |
