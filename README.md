# digital-warehouse 🏠

> A project aiming to enable families to manage all the expensive stuff in the household.
>
> 帮助每个家庭管理茶叶、酒品等常见送礼物品的「数字仓库」——**精简版只做三件事：入库登记、出库登记、时间追踪**（存了多久、何时出的库），不记价格等复杂信息。

This was generated by Qwen Studio

## ✨ 功能（v0.3 · 精简版）

- 🍵 **礼品分类**：预置茶叶、白酒、红酒、洋酒、保健品、香烟、礼品、食品等送礼常见分类，支持自定义新分类
- 📥 **入库登记**：名称、规格、数量+单位（瓶/罐/饼/提/箱）、入库日期（默认今天）、存放位置、备注
- 📤 **出库登记**：卡片上一键「出库」（可改出库日期），也可「撤销出库」恢复在库；出库记录灰显留档
- ⏳ **时间追踪**：每条记录自动计算已存放时长；茶叶/食品/保健品存放超过一年温和提示注意赏味期，酒类陈放不加警示
- 🔍 **搜索筛选**：关键词搜索、分类过滤、仅看在库/已出库、按入库日期或名称排序
- ⬇ **数据导出**：一键导出 JSON（本地 `data/items.json` 持久化，无数据库依赖）
- 📱 **响应式界面**：桌面与手机均可使用

## 🚀 快速开始

零依赖，只需 Node.js ≥ 18：

```bash
npm start        # 或 node server.js
# 打开 http://localhost:3000
```

开发模式（文件改动自动重启）：

```bash
npm run dev
```

端口可通过环境变量修改：`PORT=8080 npm start`

首次启动会在 `data/items.json` 生成两条示例数据，可直接删除后录入自己家的物品。

## 🧱 技术选型

| 层 | 方案 | 理由 |
|---|---|---|
| 后端 | 原生 Node.js `http` 模块 | 零依赖、易部署、无需构建 |
| 存储 | JSON 文件（原子写入） | 家庭场景数据量小，备份即复制一个文件 |
| 前端 | 原生 HTML/CSS/JS + `<dialog>` | 免框架、加载快、单页即可完成 CRUD |

## 📡 API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/items?q=&category=&stock=in\|out&sort=` | 列表（搜索/分类/在库状态过滤/排序） |
| GET | `/api/items/:id` | 单条记录 |
| POST | `/api/items` | 入库登记 |
| PUT | `/api/items/:id` | 更新 |
| POST | `/api/items/:id/out` | 快捷出库（body 可带 `{date}`，默认今天） |
| POST | `/api/items/:id/in` | 撤销出库，恢复在库 |
| DELETE | `/api/items/:id` | 删除 |
| GET | `/api/categories` | 分类列表 |
| GET | `/api/stats` | 统计概览（总记录 / 在库 / 已出库 / 分类计数） |
| GET | `/api/export` | 导出全量 JSON |
