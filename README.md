# digital-warehouse 🏠

> A project aiming to enable families to manage all the expensive stuff in the household.
>
> 帮助每个家庭管理茶叶、酒品等常见送礼物品的「数字仓库」——**精简版只做三件事：入库登记、出库登记（送给谁）、时间追踪**，不记价格等复杂信息。

This was generated by Qwen Studio

## ✨ 功能（v0.5）

- 🍵 **礼品分类**：预置茶叶、白酒、红酒、洋酒、保健品、香烟、礼品、食品等送礼常见分类，支持自定义新分类
- 📥 **入库登记**：名称、规格、数量+单位（瓶/罐/饼/提/箱）、入库日期（默认今天）、存放位置、备注
- 📤 **出库登记**：卡片上点「出库」→ 弹窗填写 **送给谁 / 事由 / 出库日期 / 备注** → 确认后物品从在库列表消失，进入「出库记录」页留档
- 🧾 **出库记录页**：独立页面展示所有已出库物品（谁收的、什么场合、何时出的库、已出库多久），支持搜索、分类过滤、排序、编辑、删除
- ⏳ **时间追踪**：在库记录自动计算已存放时长；茶叶/食品/保健品存放超过一年温和提示注意赏味期，酒类陈放不加警示
- 🔍 **搜索筛选**：关键词搜索（出库记录可按收件人搜）、分类过滤、按日期或名称排序
- ⬇ **数据导出**：一键导出 JSON（含在库 + 出库记录，本地 `data/items.json` 持久化，无数据库依赖）
- 📱 **响应式界面**：桌面与手机均可使用

## 🚀 快速开始

零依赖，只需 Node.js ≥ 18：

```bash
npm start        # 或 node server.js
# 打开 http://localhost:3000
```

开发模式（文件改动自动重启）：

```bash
npm run dev
```

端口可通过环境变量修改：`PORT=8080 npm start`

首次启动会在 `data/items.json` 生成两条示例数据，可直接删除后录入自己家的物品。

## 🧱 技术选型

| 层 | 方案 | 理由 |
|---|---|---|
| 后端 | 原生 Node.js `http` 模块 | 零依赖、易部署、无需构建 |
| 存储 | JSON 文件（原子写入） | 家庭场景数据量小，备份即复制一个文件 |
| 前端 | 原生 HTML/CSS/JS + `<dialog>` | 免框架、加载快、单页即可完成 CRUD |

## 📡 API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/items?q=&category=&sort=` | 在库列表（搜索/分类过滤/排序） |
| GET | `/api/items/:id` | 单条在库记录 |
| POST | `/api/items` | 入库登记 |
| PUT | `/api/items/:id` | 更新在库记录 |
| POST | `/api/items/:id/out` | **出库**：从在库移除，携带 `{recipient, reason, outDate, notes}` 写入出库记录 |
| DELETE | `/api/items/:id` | 删除在库记录（不留档，用于误录清理） |
| GET | `/api/outbound?q=&category=&sort=` | 出库记录列表（可按收件人/事由搜索） |
| PUT | `/api/outbound/:id` | 编辑出库记录（送给谁、事由、日期、备注） |
| DELETE | `/api/outbound/:id` | 删除出库记录 |
| GET | `/api/categories` | 分类列表 |
| GET | `/api/stats` | 统计概览（在库数 / 出库数 / 分类计数） |
| GET | `/api/export` | 导出全量 JSON（含在库 + 出库记录） |
